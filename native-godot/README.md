# 慢时光原生迁移工程（Godot 4.7.2 + C# / .NET 8）

这是Godot与C#原生工程。本轮已补齐此前清单中的外观、照护、档案、天气表现、动物行为、道路工具、旧档导入和Windows便携打包。
新运行时的三维、移动、物理、选取及UI由Godot与C#执行，不调用Python、不做逐帧GPU画面回读。

## 运行

首次克隆项目后，在项目根目录运行一次 `.\native-godot\setup.ps1`。脚本将官方 Godot 4.7.2 .NET 版和 .NET 8 SDK 下载到不纳入版本管理的 `.tools/`，不修改系统安装。下载量约 400 MB，需要联网。

双击本目录`Start-Native.cmd`，或在项目根目录执行：

```powershell
.\native-godot\run.ps1
.\native-godot\run.ps1 -Editor
```

游戏自带受版本管理的`Content/world.json.gz`资源包和可直接编辑的`Content/rules.json`规则表，启动、编译、打包均不需要Python。
动物模型、外观与动作由C#程序化生成；场景静态网格作为美术资产随项目保存。默认场景资源已去除重复道路和旧动物网格，从507份网格缩减为202份。

在“经营管理 → 存档”选择旧版`manor.db`或JSON副本导入。导入自动备份当前新版存档，然后切换场景。
SQLite使用Windows自带的只读连接和一致性事务读取，包括已提交的WAL数据；不修改原库。支持v1～v6版本，拒绝未知新版本和校验失败的数据。

「经营管理 → 存档」可在 3 个小镇间切换。原有的 `user://native-save.json` 继续作为 1 号存档，每个槽各自保存历史恢复点、照片和镜头机位。存档页可查看当前文件位置和导出副本。保存格式不反向覆盖 SQLite。
资源编辑可运行`content.ps1 -Action Unpack`解包，修改后使用`-Action Pack`压缩；如果存在开发用`world.json`，启动时优先使用它。修改经济、物种、建筑目录等参数直接编辑`rules.json`即可。
原工程`tools/export_godot.py`仅保留为历史工具，已不属于新版依赖。运行工具链`.tools`仍由源码启动脚本使用；便携发行包不依赖它。

## 已验证

- 原三维程序化网格转换为Godot ArrayMesh，一次加载复用GPU资源。
- 九个区域、原生光照/阴影、树冠摆动和水面效果。
- C#道路寻路、8米道路、双向车道/中央绿化/两侧人行道、原生CharacterBody碰撞、四向红黄绿灯和行人过街相位。
- 宠物喂食、清洁、互动、改名、买卖/宠物蛋/公益领养、居所迁移与寄养。
- 成长、寿命、疾病/外伤、住院治疗、同居冲突、伴侣关系、怀孕与出生、产物与库存过期。
- 公共库存、资源预约/退款、种植/养殖/贸易、自动修路/建房/开放街区、住房和粮食约束下的家庭生育、儿童成长。
- 卫生排泄与疾病暴露、手动收集/出售粪便、管理员现场清扫/喂食与工资、饲养员托管。
- 天气/季节对环境、健康、游客与作物的影响；农田手动/自治收获、游客到离镇/消费/门票、房租和建筑税收。
- 商店与加工配方、邻里物品/宠物订单、八类突发事件、折扣/涨价、图鉴与成就奖励。
- 物品订单缺货时会显示差额。可从订单直达对应商品或配方，确认补货后返回原订单。
- 庄园建筑解锁/建造/升级/拆除；城镇旋转施工与拆除；三种道路改铺/拆除/撤销；装饰摆放/移动/旋转/撤销。
- 鼠标拖拽道路、自动接路费用预览、20笔持久化撤销、建筑与装饰的场景预览。原生管理窗口提供 17 个页面。今日待办可按伙伴照护、小镇事件、邻里订单和完工提醒筛选，支持分页并保留浏览位置。
- 「建造 → 城镇建筑」可查看实时施工进度、预计完工和道路通达状态，并定位现场。玩家项目完工后会进入「今日待办」，标为已读后收起。
- 新存档可按首日引导完成喂食、定位宠物和查看订单。引导可跳过，已有存档可从「今日待办 → 新手引导」开启。
- 首日引导完成后可打开「成长」，查看订单、庄园建筑和物种收集等目标的实际进度，以及完成目标的入口。
- 「地图」可用滚轮缩放、左键或中键拖动，按需显示施工项目、断开道路和货运路线。可点击施工标记打开工程卡，也可点击地图定位镜头。
- 场景可用左键或中键拖动平移、右键拖动旋转、滚轮指向缩放，也可用 WASD 移动。施工时左键用于放置或铺路，中键仍可平移。
- 顶栏「找村民」可按姓名、职业或街区查找，也可用全局搜索。户外村民有可点击的名字牌。定位会前往村民、驾驶中的货车或村民当前所在的住宅。
- 村民名册可查看下一站并开启跟随，拖动镜头、移动键或 Esc 退出。地图可叠加居民图层，按职业和状态过滤并展开聚合名单。职业服装帮助区分居民，遮挡选中角色的景物会局部淡化。
- 经营管理标题栏的「返回」和 Alt+左方向键可回到上一个页面。场景照护卡可直接互动、收取产物或送医，并说明操作受限的原因。「环境 → 界面显示」可开启高对比模式。
- 宠物页可进入跟随观察，按 Esc 或用 WASD 移动镜头退出。照护页可定位宠物活动区，点击食盆、浴盆或玩具可打开相应照护操作。
- 场景选中伙伴后会显示实时饱食、健康、清洁和心情，可直接打开照护详情。快速喂食会核验当前选中的伙伴和普通饲料库存。
- 宠物诊疗卡显示医院空闲床位、住院状态和治疗用药。今日待办可直达伤病伙伴的诊疗卡，康复后可办理出院，迁往有空位的适配居所。
- 喂食、洗澡或治疗缺少物资时，可从对应操作打开定向补给。确认购买后返回原伙伴和操作，再执行照护。
- 事务失败/磁盘失败回滚、自动保存与关窗保存；道路连通查询缓存。
- 「经营管理 → 存档」提供独立的离线暂停或正常速度结算设置，上限可选 1、4、8 小时。旧存档默认按正常速度结算，最多推进 4 小时。返回时可以查看实际推进时间、资源变化和待照护伙伴。
- 顶栏「视角」提供庄园全景、等距建造和宠物特写。庄园、市集和工业区有各自的屋顶、配色和装饰。12 种伙伴有各自的闲置动作。
- 晨昏色调、夜间窗灯和沿路街灯会随游戏时钟变化。窄窗口的「更多」可打开界面设置，在环境页调整字号、缩放、鸟鸣和雨声。3D 抗锯齿默认 4×，也可在界面显示中切换至 2× 或关闭。
- 在地图点击断开道路可预览新铺路线、费用和可恢复的入口。点击「确认铺路」才会扣款，仍可用道路撤销。
- 商店的「仓库批次」按到期时间列出库存，可筛选 12 游戏小时内到期的物资。订单默认按临期排序，宠物页可按名字、物种和健康、住院或寄养状态查找伙伴。
- 成长页的季节委托需要备齐物资、等居民完成一趟实际货运，再于次日或以后交付。备货只核对库存，交付时扣除物资并结算奖励。
- 宠物近景使用更集中的阴影范围。场景中的动物、建筑和设施可悬停查看操作提示，宠物名字牌可点击选中。地图缩小时聚合同类密集标记，点击可放大查看。
- 顶栏「设置／更多」可进入拍照模式和智能快进。F10 暂停取景，F12 分别保存照片，伙伴档案提供相册。快进可以等到次日早上、下一项工程完工或季节委托交付时段，遇到紧急照护会提前恢复正常速度。
- 物品订单和季节委托可预留指定库存批次，支持临期提醒和手动释放。批量照护会在确认前列出伙伴、消耗和跳过原因。
- 自治页展示各街区的生产、公共库存、货车状态和阻塞原因。存档页保留最多 8 个恢复点，恢复前备份当前进度。
- 道路、建筑和装饰更新会复用未变化的场景节点。可运行 `.\native-godot\run.ps1 -LargeTownSmoke` 检查大型存档的道路改铺、页面切换和保存。
- 管理页头像按可见范围逐帧加载并复用。买卖、照护和交付保留当前页面，增删道路时只将受影响的路线及正在等待的角色排队处理。伙伴从自己的居所出发，迁居和住院会前往对应建筑，夜间回居所休息。
- 「设置／更多」可搜索伙伴、物品、街区、工程和订单，默认快捷键 Ctrl+F。「环境」可自定义键盘操作及动作提示音，「视角」可保存三个机位和返回上个现场。
- 近处草地、土路和石板路有独立材质细节。「建造」可按主题选装饰、调整屋顶与外墙配色、查看建筑改造影响，或先在「蓝图」把多项施工排好后一次提交。
- 「订单」可汇总多个订单的物资缺口。「财务」可查看未来 24 游戏小时的庄园与公共支出。「环境」可选择农田地块、作物和收获去向。
- 「今日待办」提供七天周历。「建造 → 蓝图」可保存当前槽的模板并重新选址报价。「商店 → 加工坊」支持排队和预留材料，「仓库批次」可配置临期提醒和处理策略。「环境」可给农场管理员设置地块优先级和每日喂食上限，「自治」可查看和排序待运物资。
- 周末集市与伙伴展示日可在「事件」查看，现场参与能兑换主题装饰。不同伙伴会选择不同活动设施，实际使用记入档案。农田地块在场景显示生长阶段，街区有独立可调的空间音效。
- 「环境 → 界面显示」可选省电、平衡和清晰三档画质，联动阴影、植被、雨雪和帧率上限。大型压力场景还包含密集路口和镜头拖动测试。
- 启动遇到无法读取的主档时，可预览该槽可用恢复点并导出原文件。恢复前会保留主档副本。关窗写入失败时可留在游戏、重试或另存副本后退出。
- 施工预览提供占地格、门口和冲突标记，路边吸附可单独关闭。重叠对象可轮选，场景资料可固定。全局搜索支持分类和最近访问，地图图钉及备注会随存档保留。
- 拍照模式支持三分线、伙伴看镜头及名字和游戏日期题签。环境页可分别关掉定位飞镜、雨雪粒子和跟随鼠标的悬停提示。
- 伙伴详情显示健康趋势与风险。购买宠物蛋会进入孵化台并预留居所空位，幼崽可用专属护理。家庭页可查看住宅切面。游客在实际到达景点后结算收入，完成邻里故事会留下可定位的街区成果。
- 仓库可设物资下限并查看预计可用天数。订单卡显示预计净收益，挑战订单单列。农田可浇水、轮作并提前安排下一茬。
- 正常启动会展示资源、存档和离线结算进度。庄园角色共享避障数据，自动保存先在后台写临时文件，再按保存顺序提交。「存档 → 整槽迁移」可预览并导入进度、机位、照片和选中的恢复点。
- 主界面将日期、天气、金币和操作分开显示。时间倍率可直接选择，目标快进时可从顶栏停止。左下角可按需展开操作速查，选中伙伴时显示四项照护数值和低值提示。
- 经营手账在小窗口按组收起。F6 聚焦当前页，方向键浏览，回车打开。标题旁的星标可收藏四个常用页面，返回按钮显示上一页去向。操作反馈可复制全文或收起。
- 地图可用按钮或键盘缩放，方向键平移。图例显示图层数量，选择图钉或村民后可查看详情。图层偏好可恢复默认，图钉可按名称或备注查找并移动。
- 伙伴名册可按照护优先级和名字排序。商店可快速填入购买数量及实际可购上限，订单可按可交付状态排序并查看备货进度，城镇建筑可按名称、用途和预算筛选。存档页显示待写入进度及各槽的主档、照片和恢复点信息。
- 搜索支持组合关键词和直达经营页面。方向键选择结果，Page Up / Page Down 翻页，Enter 执行主要操作，Shift+Enter 可执行条目显示的次要操作。
- 村民名册可按所在位置和收藏筛选，分开显示当前地点与下一站。场景定位卡可返回名册、查看住宅室内或继续跟随上一位村民。
- 小镇周历可按日期和类别查看事项。「今日待办」可筛选需要处理的条目，并回看已读的孵化和完工消息。「事件」提供进行中活动、未来场次和参加条件。
- 拍照可按原画面、16:9、1:1 或 3:4 导出。伙伴相册显示照片日期和尺寸，可按比例或收藏筛选，大图支持方向键翻页。收藏标记保存在本机，整槽迁移包包含原始照片。
- 「环境」的设置目录可直接跳到画质、键盘、镜头、声音或农场。显示页列出当前画质参数并可恢复默认。镜头支持调整滚轮步长、缩放中心、旋转速度和方向。快捷键重合时可确认交换。总音量与静音保留各项音量比例。
- 仓库可按物资查看可用、预留和临期数量，点选后查看对应批次。加工坊支持按配方和原料搜索，选择批数后显示实际缺料和费用。等待中的批次可在查看退款后确认取消。
- 蓝图草稿支持编辑、排序及撤销。项目按顺序显示校验状态，可聚焦草图或查看三维现场。已保存模板可先预览新坐标及报价，再载入草稿。
- 财务统计支持近 24 游戏小时、7 天和 30 天，可从图表定位对应账目。工资预测显示扣款顺序和首个资金缺口。日志可按文字、时间及近期或归档来源筛选。
- 「视角」可管理和命名机位，Alt+左／右可在本次游玩的定位历史里前进和后退。右下角镜头工具显示方向和距离，可缩放或朝北。固定场景资料可定位对应目标，重叠轮选支持数字键直达。
- 「照护」提供优先清单和诊疗台。健康记录可看近 3 或 7 游戏日，批量照护可指定伙伴。补给页显示可用库存和缺料报价，可返回原照护操作。
- 「环境 → 农田种植计划」同时展示三块地的状态，可查看成熟倒计时、采收分配和作物比较。从场景定位卡可在地块间切换并返回计划。管理员卡显示当前任务和喂食配额。
- 存档槽可设置本机名称。恢复点可按来源或文件状态筛选，恢复前可比较与当前进度的差异。迁移时可查看目标槽状态，离线设置可预估下次离开时实际推进多久。
- 「宠物」操作前会列出搬家和繁育的条件。场景中的结伴活动会写入伙伴档案。新订单可定位真实发布居民，并逐步解锁邻里故事。季节委托随年份和可用设施轮换，预留或备货后会固定本季方案。
- 「地图」显示镜头位置和朝向，可检查地块、输入或复制坐标，并测量两点的直线距离和现有道路距离。切页时保留本次游玩的地图缩放和中心。
- 「自治」显示实际运输进度，可按物资和发运状态筛选，定位装卸点，查看需处理的街区和最近 12 条成功卸货回执。
- 「家庭 → 住宅」可筛选空屋、比较待安置家庭需要的床位、定位真实门口，并查看成员在家状态。住宅切面可切换视角或聚焦在家的居民。
- 「成长」可按进度筛选并追踪一个目标。季节委托分开展示备货、路网、实际货运和交付时段，缺料时可直达补给入口。完成后随档保留最近 12 季的交付记录。
- 「外观」可搜索伙伴，用实际毛色样本挑选造型，旋转预览并对照已保存外观。每只伙伴的草稿在本次游玩期间保留，收藏可载入草稿再保存。
- 「自治 → 游客游览」分开显示累计到达与当前旅人状态，可筛选景点、定位入口或旅人。存档保留最近 12 条实际到达消费明细。
- 「建造 → 城镇建筑」的工程名册支持筛选和分页，可直达下一项完工工程及其临街道路。拆除单独查看退款、影响和受限原因，确认时重新核对。
- 「档案」分为伙伴档案、物种图鉴和小镇记录。可搜索伙伴足迹、按收集记录筛选图鉴，并回看订单奖励和事件选择。旧记录缺失的时间与选项会标为未记录。
- 伙伴相册支持本机照片说明、按文件名和日期搜索、排序以及大图放大拖动。可另存原始 PNG 副本，已有文件会保留。
- 「事件」分开显示待处理事件和周末活动。活动页列出路网、现场、居民到达和参加材料等条件，可查看伙伴资格、剩余奖励并跳转装饰目录。存档保留最近 12 次成功参加的明细。
- 「建造 → 装饰」可按主题、预算和活动奖励筛选，预览实际模型。已摆放装饰可搜索、定位和复制为新摆放草稿。移除前会显示实际退款和撤销规则。
- 顶栏速度和「设置／更多」可打开「时间计划」，预览目标时刻和预计现实用时。可等待实际农田成熟或已开工的加工批次结束。目标变化、紧急照护和正常到达都会在本次游玩留下最近一次结果。
- Debug 编译 0 错误 0 警告，117 项规则回归覆盖旧档迁移、蓝图、加工队列、库存、农田、宠物孵化和游客消费。住宅、管理员、四向信号、居民货运和迁移场景检查均提供独立入口。

## 固定家庭与夜间回家

- 每位常住居民分配具体的已完工住宅，房屋与家庭关系写入原生存档；伴侣和未成年子女同住，新生儿继承母亲住所。旧存档首次加载会一次性补齐初始安置住宅。
- 每天20:00打断外出路线，沿道路走到自己的家门前后进入室内；室内居民隐藏并退出道路碰撞。07:00依次出门，继续工作与日常活动，夜间未完成工作保留剩余工时。
- 点击带“住宅 · 点击查看家庭”门牌的房子，查看成员姓名、性别、年龄、职业、配偶/父母和当前状态。也可从“经营管理 → 家庭”定位住宅。年龄使用游戏日，沿用7日成年的模拟规则。
- 道路中断时保留住房，居民等待道路修复；有人居住的住宅禁止拆除。后续人口增长需要真实空床，不会靠每次加载重复生成房屋。
- 顶栏显示游戏时钟，基础天空与照明随昼夜变化。游客继续按访问时程离镇。

## 本轮补齐的迁移功能

- 外观：每种动物384种组合；兔子毛色、花纹、耳型和额毛，其他动物配色、花纹、体态和点缀。三维预览、每种12个收藏、恢复初始外观；默认样式散列与旧版兼容。
- 照护：批量喂食、洗澡、互动、收产物；按需要照护，缺料、寄养和冷却会跳过，写盘失败整批回滚，不使用腐败物喂食。
- 财务与档案：7/30日收支柱图、原因筛选与分页明细；宠物亲属、年龄、病史、离世/离园档案、完整生平；图鉴、订单/事件归档与全部日志分页检索。
- 世界表现：四季植被换色、冬季覆雪色调、雨/雪/雨夹雪粒子；居民阅读、锄地、喂养、生产、搬货道具和动作；公共羊群数量对应真实公共牲畜库存。
- 宠物：按饥饿和心情前往食盆或玩具，与伙伴互动，闲逛、眨眼、夜间/低健康休息；本地寻路绕开实际墙体，保留动物间碰撞。视觉行为不消耗经营随机数，不凭空增加食物或属性。
- 道路：按住左键拖拽，松开提交整笔；整笔费用和非法位置预览、自动接入主路、20笔连续撤销与重载恢复。`R`旋转建筑，`Ctrl+Z`撤销道路，`M`打开地图；地图可定位镜头并显示地价。
- 迁移与发行：C#原生旧SQLite/JSON导入，v1～v6、WAL、版本拒绝和自动备份检查；不需要Python或.NET SDK的Windows x64便携包。

完整迁移对照与验证范围见[MIGRATION.md](MIGRATION.md)。旧源码可以归档；建议保留原SQLite存档及备份，方便回到旧版。
原生随机数算法与原版不同，天气独立使用哈希随机源；可恢复同一原生存档的随机状态，但不承诺与Python逐次随机结果相同。
居民自治经营任务以游戏时钟完成；工作道具和公共羊群表现属于场景展示。农场管理员在线清扫和喂宠物需要实际到达目标，居民货运也需要真实行驶；离线不虚构货车送达。界面和美术已按Godot重做。

## Windows便携包

```powershell
.\native-godot\package.ps1
```

生成`native-godot/dist/TownGame-Windows-时间/`及ZIP。解压后双击`Start-Town.cmd`，保留整个目录即可复制到其他Windows x64电脑，不需要Python、SDK或原工作区。
包内包括Godot .NET运行程序、.NET 8运行时、编译程序集、场景资产及许可证；这不是单文件EXE。源码启动仍使用根目录`.tools`，不能只删除这个工具目录后继续使用`Start-Native.cmd`。
打包产物已从源码编译和Godot资源扫描中排除，重复打包不会产生重复类定义。

## 农场管理员

- 从“经营管理 → 环境”雇佣。管理员根据真实待办在庄园内寻路，绕开房屋和障碍，朝向随移动及作业目标改变；没有任务时停下待命。
- 地面粪便有可见模型，清扫完成后消失并入库。动物饱食度低于70时自动安排喂食，每次消耗一份普通饲料；极度饥饿优先处理，平时轮流处理清扫和喂食。
- 喂食时动物暂停走动并播放进食动作；管理员有扫帚/饲料碗和工作状态。点击管理员可查看状态、累计清扫和喂食次数，点击粪便也可手动清理。
- 缺饲料、仓库满、通道堵塞或工资不足时显示原因。途中目标被手动处理、出售、寄养或迁移会重新安排；存档保留任务和位置，重载后重新确认到达。

## 路网、白天工作与居民货运

- 场景道路由4米拓宽到8米；地块布局按水平方向扩展，人物和车辆保持实际尺寸。道路有中央绿化带、双向车道及两侧1.2米人行道，路口留出斑马线和停止线。
- 每个实际进口单独配置朝向来车的红黄绿灯，行人使用独立信号。南北、东西、行人分时放行；已经进入路口的车辆继续驶离。
- 首次加载新版本会一次性补齐各街区和建筑入口的公共道路，保留原建筑、家庭归属和库存。密集的庄园宠物建筑使用通往大门的内部步道；后续玩家拆路不会在重载时自动恢复。
- 白天居民按职业前往工作区，新增12位有姓名、职业和工作地点的通勤者，覆盖农田、牧场、商业、工业、都市和公园；20:00后居民回家，通勤者离镇。区域下拉框会定位各区建筑和工作地点。
- 移除12辆无司机背景车，改为一辆由空闲成年居民驾驶的货车。司机步行上车，驶往生产区装货，运到商业区卸货，再回庄园下车；货物从公共库存实际扣除，送达收入进入公共预算，并保留居民口粮。
- 司机预约期间不再接其他自治任务。路断时保留车上货物等待修复，司机离开时退回货物；重开存档不会重复装卸。夜间不派新单，在途司机完成运输回库后回家。离线期间不虚构实际运输完成，继续保存车与货物状态。
- “经营管理 → 自治”显示道路接通情况、司机、货物和已完成趟数，并可定位货车；点击货车也能查看运输信息。
