# 慢时光原生迁移工程（Godot 4.7.2 + C# / .NET 8）

这是Godot与C#原生工程。本轮已补齐此前清单中的外观、照护、档案、天气表现、动物行为、道路工具、旧档导入和Windows便携打包。
新运行时的三维、移动、物理、选取及UI由Godot与C#执行，不调用Python、不做逐帧GPU画面回读。

## 运行

本工作区已下载便携Godot与.NET SDK到`.tools/`，没有修改系统安装。

双击本目录`Start-Native.cmd`，或在项目根目录执行：

```powershell
.\native-godot\run.ps1
.\native-godot\run.ps1 -Editor
```

游戏自带受版本管理的`Content/world.json.gz`资源包和可直接编辑的`Content/rules.json`规则表，启动、编译、打包均不需要Python。
动物模型、外观与动作由C#程序化生成；场景静态网格作为美术资产随项目保存。默认场景资源已去除重复道路和旧动物网格，从507份网格缩减为202份。

在“经营管理 → 存档”选择旧版`manor.db`或JSON副本导入。导入自动备份当前新版存档，然后切换场景。
SQLite使用Windows自带的只读连接和一致性事务读取，包括已提交的WAL数据；不修改原库。支持v1～v6版本，拒绝未知新版本和校验失败的数据。

新运行时保存到Godot的`user://native-save.json`，可在存档页查看实际位置和导出副本。保存格式不反向覆盖SQLite。
资源编辑可运行`content.ps1 -Action Unpack`解包，修改后使用`-Action Pack`压缩；如果存在开发用`world.json`，启动时优先使用它。修改经济、物种、建筑目录等参数直接编辑`rules.json`即可。
原工程`tools/export_godot.py`仅保留为历史工具，已不属于新版依赖。运行工具链`.tools`仍由源码启动脚本使用；便携发行包不依赖它。

## 固定家庭与夜间回家

- 每位常住居民分配具体的已完工住宅，房屋与家庭关系写入原生存档；伴侣和未成年子女同住，新生儿继承母亲住所。旧存档首次加载会一次性补齐初始安置住宅。
- 每天20:00打断外出路线，沿道路走到自己的家门前后进入室内；室内居民隐藏并退出道路碰撞。07:00依次出门，继续工作与日常活动，夜间未完成工作保留剩余工时。
- 点击带“住宅 · 点击查看家庭”门牌的房子，查看成员姓名、性别、年龄、职业、配偶/父母和当前状态。也可从“经营管理 → 家庭”定位住宅。年龄使用游戏日，沿用7日成年的模拟规则。
- 道路中断时保留住房，居民等待道路修复；有人居住的住宅禁止拆除。后续人口增长需要真实空床，不会靠每次加载重复生成房屋。
- 顶栏显示游戏时钟，基础天空与照明随昼夜变化。游客继续按访问时程离镇。

## 本轮补齐的迁移功能

- 外观：每种动物384种组合；兔子毛色、花纹、耳型和额毛，其他动物配色、花纹、体态和点缀。三维预览、每种12个收藏、恢复初始外观；默认样式散列与旧版兼容。
- 照护：批量喂食、洗澡、互动、收产物；按需要照护，缺料、寄养和冷却会跳过，写盘失败整批回滚，不使用腐败物喂食。
- 财务与档案：7/30日收支柱图、原因筛选与分页明细；宠物亲属、年龄、病史、离世/离园档案、完整生平；图鉴、订单/事件归档与全部日志分页检索。
- 世界表现：四季植被换色、冬季覆雪色调、雨/雪/雨夹雪粒子；居民阅读、锄地、喂养、生产、搬货道具和动作；公共羊群数量对应真实公共牲畜库存。
- 宠物：按饥饿和心情前往食盆或玩具，与伙伴互动，闲逛、眨眼、夜间/低健康休息；本地寻路绕开实际墙体，保留动物间碰撞。视觉行为不消耗经营随机数，不凭空增加食物或属性。
- 道路：按住左键拖拽，松开提交整笔；整笔费用和非法位置预览、自动接入主路、20笔连续撤销与重载恢复。`R`旋转建筑，`Ctrl+Z`撤销道路，`M`打开地图；地图可定位镜头并显示地价。
- 迁移与发行：C#原生旧SQLite/JSON导入，v1～v6、WAL、版本拒绝和自动备份检查；不需要Python或.NET SDK的Windows x64便携包。

完整迁移对照与验证范围见[MIGRATION.md](MIGRATION.md)。旧源码可以归档；建议保留原SQLite存档及备份，方便回到旧版。
原生随机数算法与原版不同，天气独立使用哈希随机源；可恢复同一原生存档的随机状态，但不承诺与Python逐次随机结果相同。
居民自治经营任务以游戏时钟完成；工作道具和公共羊群表现属于场景展示。农场管理员在线清扫和喂宠物需要实际到达目标，居民货运也需要真实行驶；离线不虚构货车送达。界面和美术已按Godot重做。

## Windows便携包

```powershell
.\native-godot\package.ps1
```

生成`native-godot/dist/TownGame-Windows-时间/`及ZIP。解压后双击`Start-Town.cmd`，保留整个目录即可复制到其他Windows x64电脑，不需要Python、SDK或原工作区。
包内包括Godot .NET运行程序、.NET 8运行时、编译程序集、场景资产及许可证；这不是单文件EXE。源码启动仍使用根目录`.tools`，不能只删除这个工具目录后继续使用`Start-Native.cmd`。
打包产物已从源码编译和Godot资源扫描中排除，重复打包不会产生重复类定义。

## 农场管理员

- 从“经营管理 → 环境”雇佣。管理员根据真实待办在庄园内寻路，绕开房屋和障碍，朝向随移动及作业目标改变；没有任务时停下待命。
- 地面粪便有可见模型，清扫完成后消失并入库。动物饱食度低于70时自动安排喂食，每次消耗一份普通饲料；极度饥饿优先处理，平时轮流处理清扫和喂食。
- 喂食时动物暂停走动并播放进食动作；管理员有扫帚/饲料碗和工作状态。点击管理员可查看状态、累计清扫和喂食次数，点击粪便也可手动清理。
- 缺饲料、仓库满、通道堵塞或工资不足时显示原因。途中目标被手动处理、出售、寄养或迁移会重新安排；存档保留任务和位置，重载后重新确认到达。

## 路网、白天工作与居民货运

- 场景道路由4米拓宽到8米；地块布局按水平方向扩展，人物和车辆保持实际尺寸。道路有中央绿化带、双向车道及两侧1.2米人行道，路口留出斑马线和停止线。
- 每个实际进口单独配置朝向来车的红黄绿灯，行人使用独立信号。南北、东西、行人分时放行；已经进入路口的车辆继续驶离。
- 首次加载新版本会一次性补齐各街区和建筑入口的公共道路，保留原建筑、家庭归属和库存。密集的庄园宠物建筑使用通往大门的内部步道；后续玩家拆路不会在重载时自动恢复。
- 白天居民按职业前往工作区，新增12位有姓名、职业和工作地点的通勤者，覆盖农田、牧场、商业、工业、都市和公园；20:00后居民回家，通勤者离镇。区域下拉框会定位各区建筑和工作地点。
- 移除12辆无司机背景车，改为一辆由空闲成年居民驾驶的货车。司机步行上车，驶往生产区装货，运到商业区卸货，再回庄园下车；货物从公共库存实际扣除，送达收入进入公共预算，并保留居民口粮。
- 司机预约期间不再接其他自治任务。路断时保留车上货物等待修复，司机离开时退回货物；重开存档不会重复装卸。夜间不派新单，在途司机完成运输回库后回家。离线期间不虚构实际运输完成，继续保存车与货物状态。
- “经营管理 → 自治”显示道路接通情况、司机、货物和已完成趟数，并可定位货车；点击货车也能查看运输信息。

```powershell
.\native-godot\run.ps1 -Smoke
.\native-godot\run.ps1 -Benchmark

.\native-godot\run.ps1 -Verify

```

性能运行会关闭垂直同步，预热300帧再测1500帧，固定镜头并禁用用户相机输入。
使用单调墙钟记录帧间隔；结果与截图分别写入`.test-output/native-benchmark.json`和`native-godot.png`。
`-Benchmark`只测场景和移动；`-BenchmarkSimulation`额外以固定每帧1/60秒、倍率600推进约5个游戏小时，
输出`native-business-benchmark.json`和`native-business-godot.png`，不读取或写入玩家原生存档。
本轮RTX5060 Laptop、1440×900窗口短场景采样：1500帧平均364.7FPS，均值2.742ms，P95 3.933ms，记录见工作区`.test-output/native-benchmark.json`。
同机推进约5个游戏小时的经营采样平均283.6FPS，均值3.525ms，P95 6.409ms，记录见`.test-output/native-business-benchmark.json`。
这只代表当前短场景负载，不能外推到大人口、长期经营或其他硬件。

住宅场景检查使用临时内存状态：真实物理步行、全部初始居民入室、房屋射线选取与家庭面板、同户居民清晨排队出门。
`-ResidencePreview`额外打开窗口并保存`.test-output/native-household.png`，不会读写玩家原生存档。
管理员场景检查验证实际绕障、到达后清扫和喂食、转向及空闲待命；`-FarmPreview`保存`.test-output/native-farm-manager.png`，同样不读写玩家存档。
货运场景检查验证四向灯面与停车规则、白天工作人员，以及司机步行上车、实际跨区运输、装卸和回库下车。`-FreightPreview`保存载货、回库和路口截图，使用独立内存状态。
迁移场景检查覆盖15个页面、12物种六种动作模型、三角形朝向、季节雨雪切换、公共羊群、居民道具、道路预览、鼠标拖拽提交/扣费/撤销和视觉随机数隔离。所有验证入口均不读取或写入玩家原生存档。
